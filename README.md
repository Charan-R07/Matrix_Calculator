# Matrix Calculator in C

## 📌 Project Introduction

The **Matrix Calculator** is a menu-driven mathematical application developed using the C programming language. The main objective of this project is to perform various matrix operations efficiently and accurately through a simple, user-friendly console interface. The program allows users to enter matrix dimensions and elements and perform eight different operations: **Row Echelon Form (Reduced Matrix), Matrix Transpose, Adjoint, Matrix Addition, Matrix Subtraction, Matrix Multiplication, Element-wise Matrix Division, and Determinant Calculation**. It uses fundamental C programming concepts such as functions, arrays, nested loops, conditional statements, recursion, and user input validation to process matrix calculations. The application also includes error handling for invalid dimensions, incompatible matrix operations, division by zero, and invalid menu selections. Overall, this project demonstrates the practical implementation of mathematical concepts and core C programming techniques in developing a functional matrix calculator.

---

## 🛠️ Technologies Used

- **Programming Language:** C
- **Compiler:** GCC / Any Standard C Compiler
- **Interface:** Console-Based User Interface
- **Header File:** `stdio.h`

## ✨ Main Operations

1. Row Echelon Form / Reduced Matrix
2. Matrix Transpose
3. Adjoint of a Matrix
4. Matrix Addition
5. Matrix Subtraction
6. Matrix Multiplication
7. Element-wise Matrix Division
8. Determinant Calculation

## 🎯 Project Objective

The objective of this project is to develop a functional matrix calculator that simplifies common matrix computations while demonstrating the use of basic and intermediate C programming concepts, including functions, arrays, loops, recursion, and conditional statements.
